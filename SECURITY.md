# Security

Trust the Process is read-only endpoint investigation software, not a security boundary or antivirus replacement. See [the threat model](docs/security.md) before interpreting results or sharing telemetry.

For a suspected software vulnerability, use the repository's private vulnerability reporting feature if enabled, or contact the repository owner privately. Do not publish credentials, command lines, user directories, live database files, or real-host reports in public issues. Use the isolated demo to reproduce display and detection issues where possible.
